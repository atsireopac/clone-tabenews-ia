# clone-tabenews-ia
Implementação do https://tabnews.com.br para o https://curso.dev utilizando agentes de IA

Projeto em Next.js 16.2.12 com App Router. Requer Node.js 20.9 ou superior.

```sh
npm install
npm run dev
```

Acesse http://localhost:3000. A página está em `app/page.js`.

Para executar em produção:

```sh
npm run build
npm start
```
